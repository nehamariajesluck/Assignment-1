# Assignment-1

This project performs Exploratory Data Analysis (EDA) on the Default of Credit Card Clients Dataset using Python. The analysis focuses on understanding customer demographics, credit limits, bill amounts, payment history, and factors associated with credit card default.

## Libraries Used

- Pandas
- NumPy
- Matplotlib
- Seaborn

## Analysis Performed

- Data Loading and Inspection
- Data Shape and Structure Analysis
- Missing Value Detection
- Duplicate Record Identification and Removal
- Data Type Verification
- Descriptive Statistical Analysis
- Unique Value and Frequency Analysis
- Correlation Analysis
- Data Visualization and Pattern Identification


## Key Objectives

- Understand the structure and quality of the dataset.
- Explore customer credit and payment behavior.
- Identify patterns and relationships among variables.
- Detect outliers and trends through visualization.
- Generate insights that can support credit risk assessment and future predictive modeling.
